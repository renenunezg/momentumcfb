# Public examples

`validation_summary.csv` is a compact export of the frozen historical evaluation artifacts.
It contains aggregate metrics only and does not include provider data or game-level outcomes.

`synthetic_serving_anchors.csv` demonstrates the outcome-free input contract used by in-game serving.
The teams and game identifiers are fictional.
The fixture is documentation and is not part of model evaluation.

Large raw, processed, and prediction artifacts remain under the ignored `backend/data/` directory.
